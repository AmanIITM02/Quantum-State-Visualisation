# Quantum State Visualization

Visualizing single-qubit quantum states, Bloch sphere representations, and quantum gate operations using Python and QuTiP.

## Project Overview

This repository contains a collection of Python notebooks demonstrating the visualization of quantum states using the Bloch sphere. The project is being developed progressively, starting from computational basis states and advancing toward superposition states, quantum gates, and qubit state evolution.

## Current Notebook

- **01_Bloch_Sphere_Basis_State_Visualization.ipynb**
  - Creates a Bloch sphere using QuTiP.
  - Visualizes the computational basis state **|0⟩**.
  - Introduces the fundamental representation of a single qubit.

## Technologies Used

- Python
- QuTiP
- NumPy
- Matplotlib
- Google Colab
